Puzzler

This first version makes puzzles directly in the browser. Sudoku, mazes, nonograms, cryptograms, full logic grids, and layouts are generated locally. Crosswords use curated clues for each difficulty. Word finds and scrambles can quietly add new vocabulary from Datamuse when online. Trivia loads batches from Open Trivia DB and keeps a local played-question history.

Each puzzle board starts zoomed all the way out so the full board fits like a page in a book. You can pinch inside the puzzle area to zoom that board, while the rest of the page scrolls normally. Progress and no-repeat history stay on this device.
